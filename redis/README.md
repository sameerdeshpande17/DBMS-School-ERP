# Redis Stack secondary database
Redis is not the source of truth for school records. MySQL owns all 11 relational entities. RedisJSON stores notice/resource documents and RediSearch supports text/tag and vector retrieval.

Start on Windows:

    docker run -d --name school-redis --restart unless-stopped -p 6379:6379 -p 8001:8001 redis/redis-stack:latest
    docker exec -it school-redis redis-cli PING

Vector fields must contain actual embeddings generated by the same text-embedding model for stored documents and search queries. Do not label arbitrary numeric arrays as AI embeddings. The app integration and model-backed embedding generation remain a later implementation stage.
